# OCEAN Hygiene Solutions

Website voor OCEAN: sanitaire hygiëneoplossingen en verbruiksartikelen voor bedrijven.

## Starten

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Beheer: [http://localhost:3000/admin](http://localhost:3000/admin)  
Wachtwoord: `Ocean2026!`

Teksten, contactgegevens en offerte-aanvragen staan in `localStorage` van de browser.
